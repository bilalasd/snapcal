# Accent rebrand: magenta → vermilion (`accent-log`)

**Date:** 2026-07-17 · **Status:** approved (visual companion session, option C)

## Decision

Replace the brand accent `#ff3d8b` (magenta) with `#e64a19` (vermilion) across
the mobile app and DESIGN.md. The Tailwind token is renamed `magenta` →
`accent-log` (semantic — named for its job, survives future recolors) and ships
as a full 11-shade scale with `DEFAULT`, generated by the color-palette skill.

User picked vermilion (option C) from four candidates shown next to Bevi on
the app's real light/dark backgrounds, accepting the one documented tradeoff:
vermilion sits near the destructive red on the color wheel.

## Changes

### 1. Token — `apps/mobile/tailwind.config.js`

Replace `magenta: "#ff3d8b"` with:

```js
"accent-log": {
  50: "#fcf5f2", 100: "#f9eae6", 200: "#f4d2c7", 300: "#eda791",
  400: "#e87754", 500: "#e64a19", 600: "#b83a14", 700: "#973011",
  800: "#7c270e", 900: "#5c1d0a", 950: "#2e0f05",
  DEFAULT: "#e64a19", // bg-accent-log resolves here
},
```

Static, shared across themes, exactly as magenta was. Unused shades cost
nothing (classes are generated on use).

### 2. Call sites — `bg-magenta` → `bg-accent-log` (5, mechanical)

- `apps/mobile/app/(tabs)/_layout.tsx` — FAB (~316), speed-dial circles
  (~289), listening dot (~263)
- `apps/mobile/components/speak-capture.tsx` — recording dot (~139)
- `apps/mobile/app/(tabs)/index.tsx` — streak badge (~319)

Line numbers indicative; `grep -rn bg-magenta apps/mobile` is authoritative.
White glyphs on the FAB/speed dial stay white (3.9:1, above the 3:1 UI
minimum and better than magenta's 3.3:1).

### 3. Comment — `apps/mobile/global.css`

Line ~9 comment mentions magenta as the shared accent; reword to accent-log /
vermilion. No token change (the accent never lived in CSS vars).

### 4. DESIGN.md (same change, per AGENTS.md sync rule)

- §2 theme prompt: "one loud magenta accent" → "one loud vermilion accent".
- §2.1 "Magenta discipline" → "Accent discipline": `#e64a19` (`accent-log`),
  reserved for logging entry points; never decorates.
- §2.1 Bevi rule: "never sits on or in front of a magenta surface" → reworded
  for `accent-log`; rationale updated — accent and fur are now same-family, so
  separation prevents smearing together (was: clash).
- §2.2 light table row: Magenta → Accent (`accent-log`), `#e64a19`, use
  column states reality: "logging entry points ('+' FAB, speed dial),
  capture-state dots, streak badge".
- §2.2 dark table row: `#e64a19` (shared), contrast 5.0:1.
- §2.2 contrast rules: replace "(3.3:1 light, 5.9:1 dark)" with
  "(3.9:1 light, 5.0:1 dark)"; add: text on accent uses shade 600 `#b83a14`
  (5.8:1 on white) — 500 is UI-color only.
- Component table: FAB / speed dial rows say vermilion instead of magenta.
- Sweep: `grep -in magenta DESIGN.md` must return nothing when done.

### 5. Locked defaults (approved with the design)

- **Destructive stays `#d92d20`.** Accepted tradeoff of option C. Structural
  separation holds: accent = filled circles/badge, destructive = error text
  and over-target numbers.
- **Streak badge keeps the accent.** The old "'+' button + speed dial only"
  doc claim was already false; the doc now documents actual usage instead of
  the app changing.

## Measured contrast (verification baseline)

| Pair | Ratio | Rule |
|---|---|---|
| 500 `#e64a19` on white | 3.92:1 | UI ≥3:1 ✓ |
| 500 on dark `#0c0c0c` | 4.99:1 | UI ≥3:1 ✓ |
| White glyph on 500 | 3.92:1 | UI ≥3:1 ✓ |
| White text on 600 `#b83a14` | 5.75:1 | text ≥4.5:1 ✓ |

Known scale limits (only if ever used): white *text* on 500 fails 4.5:1 → use
600; dark-mode muted 400-on-900 is 4.40:1 → use 300-on-900.
